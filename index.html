PROYECTO DE DISEÑO DE ALGORITMOS

Optimización de Redes
Eléctricas Urbanas.

Un municipio necesita conectar 7 subestaciones eléctricas minimizando el costo del cableado, pero también debe optimizar las rutas de mantenimiento de sus técnicos, gestionar la carga de herramientas en los vehículos y comprimir los datos de telemetría.

Algoritmos

  • ■
    Algoritmos Voraces Prim y Kruskal para el Árbol de Expansión Mínima.
  • ■
    Divide y Vencerás Merge Sort para ordenar las aristas por costo.
  • ■
    Backtracking Búsqueda de ruta (TSP) con función de poda.
  • ■
    Programación Dinámica Mochila 0/1 (carga) y LCS (telemetría).
  • ■
    Compresión Greedy Algoritmo de Huffman para alertas de datos.

Operación y Mantenimiento de Campo

Un técnico de mantenimiento debe recorrer las subestaciones para revisar el estado de los equipos. Aquí resolverás dos decisiones críticas de su viaje:

1. ¿Qué herramientas llevar? (Mochila)

El vehículo tiene un límite de peso. Usando Programación Dinámica, se seleccionan las herramientas de mayor valor sin exceder la capacidad.

2. ¿Qué ruta tomar? (Backtracking)

Usando Backtracking con Poda, se exploran las rutas posibles y se descartan las que se vuelvan demasiado largas.

Datos y Telemetría de Sensores

Los sensores en las subestaciones envían datos constantemente al centro de control. Para que la red no colapse, debemos procesar esa información de manera inteligente:

Comparación de Historiales (LCS)

Usando Programación Dinámica (Longest Common Subsequence), comparamos los picos de voltaje de dos subestaciones para detectar si están sincronizadas o si hay una anomalía.

Compresión de Alertas (Huffman)

Enviar mensajes largos consume ancho de banda. Usando el Algoritmo Voraz de Huffman, asignamos códigos binarios más cortos a las letras que más se repiten, ahorrando bits.

Análisis de Datos (LCS)

Encuentra el patrón común entre dos historiales de voltaje.

Compresión de Alertas (Huffman)

Reduce el tamaño de los mensajes asignando códigos cortos a letras frecuentes.

Conclusiones del Proyecto

El impacto de los algoritmos en la infraestructura del mundo real.

📡

Planificación y Ahorro

Los algoritmos voraces (Prim y Kruskal) demostraron ser la solución exacta para el tendido de redes. Encontramos la ruta de 280 metros que conecta todo el sistema sin ciclos, demostrando que una buena decisión algorítmica ahorra costos millonarios en infraestructura física.

🚚

Operación Eficiente

La combinación de Programación Dinámica y Backtracking demostró que los recursos limitados (peso del vehículo) y el tiempo (ruta del técnico) pueden optimizarse. La poda descartó miles de rutas inútiles, encontrando el camino óptimo de 16.13m en milisegundos.

🧠

Manejo de la Información

Con Huffman y LCS, el sistema no solo se vuelve más rápido al comprimir alertas, sino más inteligente al detectar patrones de voltaje sincronizados entre subestaciones. Los datos se convierten en decisiones preventivas.

El poder de los algoritmos

Este proyecto demuestra que la ingeniería de software no se trata solo de escribir código, sino de elegir la estrategia correcta para el problema correcto. Desde un enfoque voraz para conectar cables, hasta una búsqueda exhaustiva con poda para trazar una ruta, cada algoritmo es una herramienta diseñada para optimizar el mundo real.
